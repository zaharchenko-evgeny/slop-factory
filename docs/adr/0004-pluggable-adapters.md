# ADR-0004: Pluggable tracker, channel, target, harness and checks

Status: accepted (28 Oct 2026)

Decision: roles and workflows use neutral terms (stages, channels, targets). `factory.yaml` selects adapters. v1 adapters: YouTrack; Slack Air Mate, local, Air session; Air and local targets; Claude, Codex and pi harnesses; jscpd, accio and repository test commands.

Consequence: GitHub Issues and other adapters are a new reference page, not a redesign.
